# Проверки этапов

Каждая ветка содержит состояние на конец соответствующего этапа.
Проверки выполняются из корня командой:

```sh
python -B -m unittest discover -s tests -v
```

| Этап | Ветка | Проверка результата |
| --- | --- | --- |
| 1 | `stage-1-parser` | 7 тестов; поля всех четырёх команд совпадают с методичкой |
| 2 | `stage-2-codegen` | 15 тестов; точное совпадение 40 эталонных байтов |
| 3 | `stage-3-memory` | 32 теста; копирование массива, общая память, JSON |
| 4 | `stage-4-alu` | 40 тестов; EQ, косвенная адресация и смещения |
| 5 | `stage-5-vector` | 43 теста; три программы вектора == 116 через CLI |

Коммиты соответствуют Conventional/Scoped Commits.
Сформированные бинарные файлы и дампы не добавляются в репозиторий.

## Результаты демонстраций

- Этап 1: поля A-E всех четырёх команд совпадают с тестами на стр. 56-57.
- Этап 2: все четыре эталонные последовательности совпадают; всего 40 байт.
- Этап 3: код 85 байт; исходный массив и копия:
  [0, 17, 116, 67108863, 42].
- Этап 4: код 60 байт; M[1200..1201] = [1, 0].
- Этап 5: каждый файл 170 байт; M[1200..1206]:
  mixed = [1, 0, 0, 1, 0, 0, 1],
  all_equal = [1, 1, 1, 1, 1, 1, 1],
  no_equal = [0, 0, 0, 0, 0, 0, 0].
  Исходные векторы сохраняются.

JSON-дампы создаются командами из README в игнорируемой папке output.
Они проверяются тестами после реального исполнения бинарного файла.
Память команд и данных общая: тест самомодификации меняет операнд будущей
команды записью в память и проверяет, что изменённый байт исполняется.

## Оформление репозитория

Проверено по кодам правил С1-С6, Г1-Г5, Р1-Р2/Р6, Ф1, А1, К1,
Ц1, М1 и И1: обязательные файлы и каталоги присутствуют;
в Git нет бинарных результатов, архивов, кэшей и настроек редактора;
Python-строки не длиннее 80 символов, функции не длиннее 40 строк,
аргументов не больше 7; функции документированы docstring.
В сравнениях используются именованные границы.
Консервативный подсчёт цикломатической сложности через AST даёт
максимум 7, включая тесты. Все пять веток проверены отдельно.
Среда проверки: Windows, Python 3.12.14, стандартная библиотека.
