# Функции и модули

Все функции и классы снабжены docstring. Ниже перечислен публичный интерфейс
реализации; имена полей команд взяты из спецификации варианта 13.

## spec.py

- `CommandSpec(name, opcode, widths, size)` - неизменяемая спецификация.
- `Instruction(spec, operands)` - неизменяемая команда с кортежем операндов.
- `Instruction.__post_init__` - проверяет количество и диапазоны операндов.
- `Instruction.fields()` - возвращает словарь полей A-E.
- `Instruction.describe()` - строка полей для тестирования первого этапа.
- `UvmError` - ошибка исходного текста, машинного кода или состояния УВМ.
- `SPECS`, `BY_NAME`, `BY_OPCODE` - таблицы четырёх команд.
- `MIN_UNSIGNED` = 0 - нижняя граница числовых полей.
- `OPCODE_BITS` = 4; `ADDRESS_BITS` = 31; `MAX_ADDRESS` = 2147483647.

## assembler.py

- `parse_number(token)` - беззнаковое десятичное или шестнадцатеричное число.
- `parse_line(line)` - одна команда без комментария; возвращает Instruction.
- `parse_source(source)` - весь исходный текст; список команд.
  Пустые строки и комментарии пропускаются, ошибки включают номер строки.

## codec.py

- `encode_instruction(instruction)` - поля в little-endian байты.
- `encode_program(program)` - последовательность команд в один bytes.
- `spec_for_byte(first_byte)` - определяет спецификацию по младшим четырём битам.
- `decode_instruction(data)` - bytes одной команды в Instruction.
  Проверяет размер, opcode и нулевые резервные биты.

## memory.py

- `check_address(address)` - проверяет целый адрес 0..2147483647.
- `check_range(start, end)` - дополнительно проверяет start <= end.
- `Memory()` - единое разреженное хранилище целых неотрицательных значений.
- `Memory.read(address)` - возвращает значение, по умолчанию 0.
- `Memory.write(address, value)` - записывает целое значение в ячейку.
- `Memory.load(binary)` - загружает каждый байт в ячейку с адресом от 0.
- `Memory.read_bytes(start, size)` - актуальные байты из общей памяти.
- `Memory.dump(start, end)` - словарь всех ячеек диапазона с ключами-строками.

## machine.py и operations.py

- `Machine(binary)` - загружает код, устанавливает pc=0 и исходный размер кода.
- `Machine.step()` - читает, декодирует и выполняет текущую команду,
  затем увеличивает pc на её размер. Ошибки содержат адрес команды.
- `Machine.run()` - цикл до конца кода; возвращает общую память.
- `load_constant(memory, operands)` - M[C] = B.
- `copy_memory(memory, operands)` - M[B] = M[C], для обеих команд копирования.
- `compare_equal(memory, operands)` - M[E] = int(M[C] == M[M[D] + B]).
- `HANDLERS` - соответствие мнемоник обработчикам.

## cli.py

- `make_parser()` - определяет команды assemble и run.
- `assemble(args)` - читает исходник, собирает и сохраняет бинарный файл;
  в режиме --test выводит байты; всегда выводит размер файла.
- `run(args)` - исполняет бинарный файл и сохраняет JSON-дамп диапазона.
- `main(argv=None)` - точка входа. Возвращает 0 при успехе, 1 при ошибке
  программы/файловой операции. argparse завершает процесс кодом 2 при
  неправильных аргументах. Все параметры описаны в README и справке --help.

Внешних зависимостей, скрытого файла конфигурации и настройки размера
памяти нет. Переменная окружения PYTHON используется только скриптами запуска.
